XERATool

> Centre of Informatics and Systems of University of Coimbra (CISUC) XEn
> Robustness Assessment Tool (XERATool) was created to generate tests to
> be executed by a Virtual Machine running over Xen environment. Written
> in Java, this tool receives an interface definition (hypercall
> interface for a given version of Xen) and a set of mutation rules that
> are used to generate scenarios and robustness tests. This set of
> scenarios and robustness tests are stored in .xml files and later used
> to generate .c files. The .xml files allow the user to see which
> values were generated by the tool, while the .c files allow the
> compilation of the tool in different Virtual Machine setups (e.g.
> different OSes). These
>
> .c files when compiled output a Loadable Kernel Module that can be
> loaded into the guest VM. Finally, to execute the tests, it is used a
> small Python script that starts the test routine contained in the LKM.
> Although it was used only for a specific version of Xen, it can be
> extended to use other version or even different mutation rules.
